# Профиль: Lohotron

- **Никнейм:** Lohotron
- **Интересы:** Деньги
- **Цель:** Зарабатывать много денег

Эта фраза означает, что тебе нужно зайти на сайт GitHub через браузер и объединить свой код с основным репозиторием. В терминале для этого ничего писать не нужно.
Вот пошаговый алгоритм, что конкретно надо сделать:
1. Зайди на сайт GitHub в тот самый репозиторий, куда ты только что отправил (запушил) свою ветку.
2. Вверху страницы ты увидишь большую желтую плашку. На ней будет написано что-то вроде: «feature/твой_ник/task-2 had recent pushes less than a minute ago».
3. Нажми на этой плашке зелёную кнопку Compare & pull request.
4. Откроется страница создания Pull Request (запроса на слияние):
	• Проверь ветки (сверху): слева (base) должна стоять твоя базовая ветка student/<твой_ник>, а справа (compare) — ветка с заданием feature/<твой_ник>/task-2.
	• Заголовок и описание: GitHub автоматически подставит туда текст из твоего коммита (например, "Добавил идею проекта"). Можно оставить как есть.
5. Нажми зелёную кнопку Create pull request внизу.
Готово! После этого страница обновится, и появится статус вашего запроса. Теперь преподаватель увидит твой Pull Request, сможет проверить код (твою идею проекта) и нажать кнопку Merge, чтобы принять работу.
Получилось найти жёлтую плашку на GitHub? Если её вдруг нет, скажи — я подскажу, как открыть Pull Request через вкладку Pull Requests вручную.
