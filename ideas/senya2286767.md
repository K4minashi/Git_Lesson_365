# Идея пет-проекта: Трекер личных привычек (Habit Tracker)

## Описание
Простое веб-приложение, которое помогает пользователю ежедневно отмечать выполнение полезных привычек (например, чтение книг, занятия спортом, изучение Git) и строит красивые графики прогресса.

## Технологический стек
- HTML / CSS / JavaScript
- Локальное хранилище данных (LocalStorage)

## Фичи
- Добавление и удаление привычек.
- Календарь с отметками выполненных задач.
- Система «страйков» (счётчик дней подряд без пропусков) для мотивации.
